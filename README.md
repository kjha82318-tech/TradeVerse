# TradeVerse 📈

A full-stack stock trading platform inspired by modern brokerage applications, built to provide an interactive interface for exploring markets and managing a trading experience.

## 🚀 Overview

**TradeVerse** is a web-based trading platform designed to simulate the experience of a modern stock brokerage application. It combines a user-facing frontend, backend services, and a dashboard into a modular project structure.

## ✨ Features

- 📊 Interactive trading platform interface
- 📈 Stock market visualization and market-oriented UI
- 🖥️ Modular frontend and backend architecture
- 🔧 Backend API integration
- 📱 Responsive web interface
- 🗂️ Separate dashboard for platform management and monitoring

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/kjha82318-tech/TradeVerse.git
cd TradeVerse
```

### 2. Install Backend Dependencies

```bash
cd backend
npm install
```

### 3. Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

### 4. Install Dashboard Dependencies

```bash
cd ../dashboard
npm install
```

## ▶️ Running the Project

Start each component from its respective directory using the scripts configured in its `package.json`.

### Backend

```bash
cd backend
npm start
```

### Frontend

```bash
cd frontend
npm start
```

### Dashboard

```bash
cd dashboard
npm start
```

> The actual start commands may differ depending on the scripts defined in each package.json.

## 🔐 Environment Variables

Configure the required environment variables in your backend `.env` file.

Example:

```env
PORT=5000
```

Add any additional variables required by your application. Do not upload secrets, API keys, or database credentials to GitHub.
